# data/

Place the two CSV files from the OSF archive here:

- `IoT_Sensor_Hourly.csv`
- `daily_features.csv`

Source: https://doi.org/10.17605/OSF.IO/7THQ4 (CC-BY 4.0)

Or download them from the command line:

```bash
curl -L -o IoT_Sensor_Hourly.csv "https://osf.io/download/mjn8x/"
curl -L -o daily_features.csv    "https://osf.io/download/6a59edbe6fd1fa85b2f9b81e/"
```

Column definitions are documented in the repository README.
